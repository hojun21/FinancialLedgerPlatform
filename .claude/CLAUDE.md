## 프로젝트
ZeroSum (가칭): 돈이 1원도 틀리지 않는 미니 코어뱅킹 원장 시스템. 은행 자바 개발자 포트폴리오이자 Spring 학습용.

## 규칙
- 파일을 직접 만들거나 수정·삭제하지 말 것. 코드는 내가 직접 친다. 어디에 무엇을 쓸지 알려 주고 설명만 할 것.
- 파일 읽기는 괜찮음. 명령어 실행은 먼저 물어볼 것.
- 나는 Spring을 처음 배운다. 한 번에 개념 하나씩, 왜 → 무엇 → 어떻게 순서로 꼼꼼히 설명할 것.
- 어노테이션은 뒤에서 무슨 일이 일어나는지까지 설명할 것.
- 에러는 답보다 힌트 먼저.
- 한국어로 설명, 용어는 영어 원어 병기.

## 도메인 규칙
- 금액에 double/float 금지 (BigDecimal 또는 long).
- 복식부기: 차변 합 = 대변 합. 원장은 수정·삭제 금지, 정정 거래로만.
- 잔고는 절대 마이너스 불가. 두 계좌 락은 ID 작은 쪽부터.
- 이체는 멱등 키로 한 번만 처리.
